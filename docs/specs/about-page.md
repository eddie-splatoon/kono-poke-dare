# データの扱いの説明ページ

## 概要

ログインや記録の外部送信がなく、記録は端末内にだけ保存することを、利用者に説明するページである。消す方法と、消すと戻らないこと、非公式のファン作品である旨、権利者向けの連絡先もここで伝える。

## 要件

| ID   | 要件                                                                               |
| ---- | ---------------------------------------------------------------------------------- |
| R-1  | ゲーム画面のフッターのリンクから `/about` を開ける                                 |
| R-2  | 問題データを取得できない画面でも、フッターのリンクから `/about` を開ける           |
| R-3  | 記録を端末内のブラウザにだけ保存することを表示する                                 |
| R-4  | 保存する項目を表示し、回答の文字列を保存しないことを表示する                       |
| R-5  | ログインがなく、記録と回答を外部へ送信しないことを表示する                         |
| R-6  | 配信元の GitHub がアクセスログを持つ可能性を表示する                               |
| R-7  | ブラウザのサイトデータの削除で消せることと、同じドメイン全体が対象になることを表示する |
| R-8  | 消すと元に戻らないことを表示する                                                   |
| R-9  | ブラウザの判断で記録が消える場合があることを表示する                               |
| R-10 | 非公式のファン作品で、権利者と関係がないことを表示する                             |
| R-11 | 権利者向けの連絡先のリンク先は、権利者向けの Issue フォームである                  |
| R-12 | `/about` を開いたときのリクエストは、すべて `basePath` の配下で成功する            |
| R-13 | `/about` を開いても、問題データを取得しない                                        |
| R-14 | `/about` からゲームへ戻るリンクで戻ると、進行が復元される                          |
| R-15 | 幅 360px で横スクロールが出ない                                                    |

## ドメインルール

- 説明は実装と一致させる。保存の実装(`records.md`)や通信を変えるときは、このページも直す
- 履歴の一覧やエクスポートなど、実装にない機能を書かない
- ブラウザごとに差がある動作を断定しない
- 同じタブで遷移する。進行は保存済みなので戻ると復元されるが、入力中の回答は消える。これは許容する
- URL は `trailingSlash: true` により `/about/` になり、`about/index.html` を配信する
- ゲーム画面と `/about` の間のリンクは、画面に入っただけでは事前取得しない(`prefetch={false}`)

## 入出力

なし

## エラー

なし。静的なページで、データの取得も保存もしない。

## セキュリティ

- Server Component のままにして、IndexedDB と問題データに触れない
- ページは新たに外部へデータを送信しない。外部へのリンクは、利用者が押したときにだけ開く
- 権利者向けのフォームは公開の Issue になるので、個人情報を書かないよう案内する
- 正解データを書かない

## 対象外

- 法的な文書の作成
- アプリ内の記録の削除機能
- 非公開の連絡窓口
