# 得点計算

## 概要

正解したときのヒント番号から得点を求める。早く当てるほど高得点になる。

## 要件

| ID  | 要件                                                                       |
| --- | -------------------------------------------------------------------------- |
| R-1 | ヒント 1〜10 の得点は、順に 100、90、80、70、60、50、40、30、20、10 である |
| R-2 | ヒント番号が 1〜10 の整数でなければ `RangeError` にする                    |

## ドメインルール

- ヒントの数は 10 個(`MAX_HINTS`)である
- 得点は `(MAX_HINTS + 1 - ヒント番号) × 10` で求める

## 入出力

| 項目             | 型       | 範囲                 |
| ---------------- | -------- | -------------------- |
| 入力: ヒント番号 | `number` | 1〜10 の整数         |
| 出力: 得点       | `number` | 10〜100 の 10 の倍数 |

## エラー

ヒント番号が範囲外、整数以外、`NaN` のときは `RangeError` を投げる。

## セキュリティ

ヒント番号は、端末内の進行状況から求める。端末内の値は書き換えられるので、範囲外の値は R-2 のとおりエラーにする。
